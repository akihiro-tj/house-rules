# サブエージェント

- 完了報告を鵜呑みにしない。セッション上限などで途中で落ちることがあるので、毎回 git の状態（未コミットの差分・ブランチ）を確かめ、中断した作業は引き継いで完了させる
- レビューや調査を任せるときは、自分で対象を読んで検証し、統合したレポートを返すように伝える（子エージェントに再委譲し、結果を統合せずに終わることがあるため）
- 実装を任せるときは、テストの期待値を観測値に合わせて書き換えず、計画と食い違ったらブロックとして報告するように伝える（計画に書かれた数値前提が間違っていることがあるため）
